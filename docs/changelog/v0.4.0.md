# Fission v0.4.0

Fission adds CLI workflows for collecting sandbox evidence, verifying recovered behavior, and analyzing raw images. Function discovery reuses eligible SLEIGH results while building instruction coverage, and decompiler control-flow preparation reads calls and jumps directly.

## CLI additions

- `sandbox` reports exploration, time-travel state, and snapshots in machine-readable output. The [sandbox documentation](../CLI.md#sandbox-execution-evidence) describes the completeness fields.
- `verify` reports machine-readable verification results. Native fixture replay and Python export have dedicated CI coverage. See the [verification documentation](../CLI.md#verify-command).
- Raw images can be loaded with an explicit base address and language. The CLI also lists available languages and surfaces DWARF source lines where they are present.

## Analysis and performance

- Function discovery records contiguous covered instruction ranges and reuses matching instruction decodes during the initial coverage walk. Reuse is bounded and depends on the address, processor context, and available bytes.
- Control-flow preparation streams call and jump references, and local no-return analysis prepares independent functions in parallel.
- The [DecBench guide](../BENCHMARK_DECBENCH.md) explains how to reproduce the corpus measurements and interpret the structural similarity metrics.

## Installation

GitHub Releases distributes the CLI and runtime resources together for Linux x64 and arm64, macOS Apple Silicon and Intel, and Windows x64. The [release checklist](../RELEASE.md) describes the unpacked-package smoke tests, SHA-256 manifest, and build attestations.
