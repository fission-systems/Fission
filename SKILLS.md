# Fission Skills

Portable AI IDE entrypoint.

- To **use** Fission on a binary (inspect, decompile, follow strings and calls,
  check a finding by execution), load [`skills/fission/SKILL.md`](skills/fission/SKILL.md).
  It covers the `--contract v1` JSON surface, the commands an agent needs, the
  traps measured on the current CLI, and how to report results.
- To **improve** the decompiler, load [`SKILL.md`](SKILL.md). It defines the
  anti-overfit decompiler improvement workflow, owner boundaries, AI prompt
  firewall, validation commands, and review rejection rules.
