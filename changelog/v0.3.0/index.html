    Fission v0.3.0¶

    Two things changed for anyone picking Fission up. It can now be installed: Homebrew, a one-line script, cargo install, or an archive for five platforms. The v0.2.x archives looked installable but were not; see below. And it has a machine contract: --contract v1 puts any command's result in one JSON envelope with typed exit codes, which is what an agent driving the tool needs.

    The rest is 204 merged pull requests since v0.2.3, mostly correctness fixes. In several of them the emitted C did something other than what the binary does, and no structure score could see it. They were found by executing code, by reading diffs, and by running debug builds over real binaries.

    Release summary¶

    Area v0.2.3 v0.3.0
    Install channels build from source Homebrew, install.sh, cargo install, archives
    Release archive works outside a source checkout no yes, smoke-tested on every target
    Release targets Linux x64, macOS arm64, Windows x64 + Linux arm64, macOS Intel
    Machine contract (--contract v1, schema, skill) none v1
    Native debugger in release binaries not compiled in Linux ptrace, macOS (Windows behind a build feature)
    AArch64 functions calling a phantom sub_N() 24 of 66 0
    PE ARM64 functions calling a phantom sub_N() 239 of 531 0
    RISC-V test binary: functions listed 3,158, mostly .L labels 66, the real functions by name
    x86-64 functions verify proves equivalent (689-function probe) — 98 → 102, none newly diverged (#846)
    Sample-set GED, exact matches / total distance not comparable* 68 / 233, distance 7,573
    Sample-set types, exact matches not comparable* 17 / 222

    * The sample-set gate was ported onto the DecBench package (#718), and DecBench's CFG parser is now rust-joern. The v0.2.3 numbers came from the old harness, so these rows are a new baseline, not a delta.

    Installing¶

    brew install fission-systems/tap/fission-cli
curl -fsSL https://raw.githubusercontent.com/fission-systems/Fission/main/install.sh | sh

    cargo install and the archives are described in the README.

    The v0.2.x archives put fission_cli beside utils/, which is not a place the binary looks for resources. Unpacked anywhere except inside a source checkout, every decompile failed with "no Ghidra language definitions were loaded". No release step had ever run an archive from outside a checkout.

    Every channel now uses one layout, bin/fission_cli beside share/fission/{sleigh-specs,signatures,ghidra-data}. The binary resolves that layout with no configuration. CD unpacks each archive in a temporary directory and decompiles from an unrelated working directory with no FISSION_* environment, so this cannot regress quietly again. Asset names no longer carry the platform nickname: fission-x86_64-unknown-linux-gnu.tar.gz replaces fission-linux-x64.tar.gz. Building the matrix for the first time also showed that aarch64 Linux had never compiled with the default debugger feature; it does now (#845).

    For agents¶

    • --contract v1 returns one JSON envelope on stdout with typed exit codes: 0 ok, 1 failed, 2 usage, 3 input, 4 partial, 5 timeout, 6 environment, 70 internal. fission_cli schema prints the envelope's JSON Schema and the stable error codes (#687, #829).
    • fission_cli skill prints the usage guide compiled into the binary, and tests keep the guide in step with the CLI (#828, #831).
    • decomp --name selects a function by exact name (#830).
    • --signature-path adds your own FID databases after the bundled ones (#833).
    • A flag that is accepted but ignored now produces a warning (#823).

    The emitted C was wrong in these places¶

    • Partial-register writes were lost when a wider register was read afterwards (#846). Examples: setz dl followed by add rax, rdx; and al, 0x7f followed by or eax, 8; shr al, 4 with EAX used whole. count_char decompiled as a function that always returns 0. Across the sample set, 609 functions changed for this fix; the noise floor between two runs of the same build is 69.
    • AArch64 csel and cinc printed a call to an address that is not a function. The lifter rewrote an instruction-internal label into an address. The builder also gave the two halves of one select different variables (#842, #844). PE ARM64 and MIPS had the same phantom calls; they are gone too.
    • AArch64 FCVT* and FRINT* used one rounding mode for all variants (#834, #838).
    • A jmp to a PLT stub is now a tail call to the stub's symbol (#836).
    • Jump tables no longer stop at 256 entries when a range check covers more (#837). A relative table switches on its index, and a table's default entry keeps its ordinal (#793, #809, #810, #811).
    • Stale call arguments. A stripped callee's proven parameter count now prunes arguments left over in registers. Measured against DWARF, correct argument counts went from 63.1% to 80.6% (#832).
    • Dead-store elimination deleted stores made through pointer variables. Field stores through a pointer were also treated as stack-slot writes (#821, #822, #826).
    • Loop conditions are no longer rewritten from a value cached before the loop (#736).
    • The optimizer erased masks on live-in registers and merged stale expressions (#733).
    • Constant division is recognized in more of its compiled forms: 64-bit unsigned, the add-correction form, signed 64-bit, and x - (x / d) * d as x % d. Functions with a leftover magic multiply went from 309 to 148 (#727, #794-#798).
    • Labels that another goto still targets are no longer removed (#750, #819, #820, #731).

    Programs read more accurately¶

    • One function discovery replaces the profile-dependent ones. Decode windows running past a function's real end went from 36% to 12%, measured against ground truth (#724).
    • ARM/Thumb mode is recorded and decoded per function in mixed images (#722, #723).
    • ELF assembler-local labels (.L*) are no longer listed as functions, which had buried RISC-V's real names. A FUNC symbol now wins its address (#843).
    • The Mach-O header symbol is no longer taken for code (#843).
    • DWARF and PDB. DWARF follows specification and abstract-origin references, and derived classes carry their bases' members. DWARF 2/3 member offsets are read, and PDB frame-pointer frames split parameters from locals (#777, #778, #802, #779).
    • Go. pclntab is read by Go version and pointer size, on Windows too (#760, #769, #803).
    • Sleigh specifications were updated from Ghidra 12.0.4 to 12.2 (#712).

    Debugging and dynamic analysis¶

    • Native debugging on macOS combines ptrace control with the Mach task port and has been verified against live processes (#704, #707).
    • Linux ptrace can launch and attach, stops at software breakpoints with the PC on the breakpoint, and steps over it on resume (#147, #761, #766).
    • Interactive sessions can be driven by an agent, and each backend reports which operations it supports (#145, #151).
    • Windows. Reading PE strings is page-aware, which fixed the two Heavy CI failures (#840).
    • The emulator, TTD and the solver received a long list of width, coherence and soundness fixes. The solver now treats an ArraySelect it cannot model as unsupported rather than as a free value (#730, #737, #742, #747, #751, #752).

    Stability¶

    • Debug-build sweeps over real binaries found four overflow and bounds panics on x86-64 ELFs (#725). A later sweep found unbounded pointer-type nesting: p = *p added a Ptr per solver round and overflowed in four functions (#846). Release builds wrap silently; both are fixed.
    • Malformed inputs that the fuzzer kept finding now fail cleanly, and then_some no longer slices before checking its condition (#709, #732, #734, #710).
    • Threads of one process no longer race on the Sleigh frontend cache's temporary file. Every installed copy printed a cache-write warning on its first decompile (#846).
    • The decompiler crate was split: fission-pcode-ir and fission-cspec are now separate crates, and static, sleigh and emulator no longer depend on fission-pcode (#694-#697).

    Known issues¶

    • x86-64 functions still diverging under verify. In the 689-function probe, 48 still diverge from the emulator. Most are compiler-rt helpers at -O0; fib at -O1/-O2 is among them.
    • Reaching definitions and calls. Reaching definitions do not yet treat a call as clobbering caller-saved registers.
    • High-byte read-modify-write. An and ah, imm read-modify-write stores only the high byte. Both this and the previous issue are pinned by ignored tests (#846).
    • Lookup tables read as strings. A lookup table whose first byte is 10 can print as the string literal "\n".
    • ARM stack arguments are not recovered (param_5 and up), and Thumb locals stay unnamed because the frame pointer is r7.
    • What is still open for 1.0. Per-command data schemas, and decisions 3-5 in docs/roadmap/1.0-criteria.md, which is why this release is 0.3.0.
